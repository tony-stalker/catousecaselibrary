requires, and not enough to satisfy "do not guess" for anything that would change a

package-manager/GitHub-style allowlist resolves). That blocks every primary source this

(or running this routine from a non-restricted environment) before the next cycle, so the
two flagged due rows (Symantec SG-S backstop, iboss 2026 MQ placement) and the quarterly
CISA KEV recount due Jan 2027 can actually be re-verified against primary sources.

run in this cloud session — run `bash _extract/verify.sh` locally before merging.
