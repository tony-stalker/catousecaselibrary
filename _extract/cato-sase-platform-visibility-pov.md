NOTES: Let’s take a closer look at the Cato SASE Cloud Platform. 
 
[Click1]
[Global Opps] At the core, we built a global private backbone of PoPs delivering our networking and security capabilities. The PoPs are interconnected with redundant Tier-1 providers that provide consistent and predictable long-haul latency, jitter, and packet loss. The PoP software selects the best route across providers, for maximum uptime and best end-to-end performance. This design offers an immediate improvement in network quality over the unpredictable Public internet, and a significant cost reduction over MPLS. 
[Regional Opps] At the core of Cato there is a cloud-first delivering our networking and security capabilities. Our PoPs are located in Top-Tier datacenters with full redundancy to deliver all our capabilities to all locations and users. You never need to buy, install, size, scale or upgrade any appliances. We seamlessly scale the service and ensure maximum performance and optimal security posture no matter how much traffic you need to support. 

[Click2]
The PoPs run a converged software stack, the Single Pass Cloud Engine software, or SPACE for short, that performs all networking and security processing in the cloud.
The SPACE is built from 2 parts: The first is a high throughput packet processing engine and the second is a threat prevention and data protection engine. 

[Click3]

The SPACE is natively built to process multi-gig traffic flows from all enterprise edges including clouds, datacenters, branches, users and devices. It supports all ports and protocols across WAN, Internet, and Cloud traffic. Digital Experience Monitoring, traffic acceleration and routing optimization help ensure performance and productivity. Decryption is applied as needed without any impact on the user experience.

[Click4]
Multiple security policies are uniformly enforced through SPACE.  FWaaS provides end-to-end segmentation of traffic. SWG protects users against phishing and malicious web sites. IPS, DNS Security, NGAM and Sandbox stop advanced threats and provide deep visibility into advanced malware . ZTNA provides secure remote access. CASB/DLP control access to risky cloud applications and prevent sensitive data loss. Finally, Remote Browser Isolation (RBI) opens web pages remotely and streams safe content to the browser, so users can browse unknown sites safely. Finally, IoT/OT provides device discovery, classification, policy enforcement and threat prevention for critical IoT and OT devices.

All these capabilities run on all traffic at the same time to minimize security overhead and leverage the rich context extracted for every packet. 

[Click5]
Customers connect all network edges to the cloud network using secure tunnels. Physical locations connect via Cato Socket Edge SD-WAN devices. 
The Cato Socket manages multiple last mile connections in active/active mode. It steers traffic to the best last mile path based on underlying link behavior. The socket applies quality of service prioritization based on application and user awareness. And, it protects critical apps like voice, video, and remote desktops against packet loss. Cato Sockets also allow local firewalling for LAN segmentation. 
Cato provides a broad set of policies out of the box that optimize traffic for the most common requirements, with the ability to configure highly granular policies for specific needs. 
Cato Sockets also support site-to-site MPLS and Internet connections to accommodate customer-specific requirements. 
Customers that already have other edge SD-WAN devices or don’t care for edge SD-WAN capabilities, can establish IPSec tunnels from existing devices to the nearest PoP and get the network and security benefits of the Cato Cloud with a zero on-site footprint. 

[Click6] 
Cato discovers, classifies, and enables secure access for IoT devices on the network. Access policies based on device attributes ensure IoT devices have a secure experience on the network. IoT devices also benefit from the threat prevention capabilities to enhance protection for these environments.

[Click7] 
Cato enables universal zero trust network for users working from remote and in the office.
A remote user uses the Cato Client , browser extension, or clientless web portal, to securely connect to any application, on premises or in the cloud, from laptops, tablets, and smartphones.  When remote, users dynamically connects to the nearest PoP as they move from place to place. Traffic is consistently optimized and secure wherever they go. 
Endpoint protection capabilities provided by Cato help govern both network and endpoint security in a single SASE platform.

[Click8]
Cloud datacenters connect using virtual SD-WAN device (the “Cato vSocket”), a cloud interconnect, or over a standard IPsec tunnel. 
The cloud datacenter becomes an integral part of the network, and its traffic is optimized and secured in the same way as all other traffic. 
There is no need to use premium cloud connection services like Azure ExpressRoute or AWS Direct Connect or virtual firewalls at the cloud edge.  Cato provides full visibility, optimization, and control over outgoing and incoming cloud DC traffic.

[Click9]
Optimization, inspection and policy enforcement are inherently applied for all cloud applications traffic. 
Application-specific traffic from any edge is automatically detected. Traffic can be forwarded, based on a network rule, over the Cato global backbone to the PoP closest to the cloud instance serving the business. This smart egress capability optimizes the user experience. An optional dedicated IP supports restricting traffic to a corporate source for SaaS applications that support this capability. 

[Click10]
An AI layer, XOps, leverages AI and ML trained models to provide customers with the insights and actions they need to quickly detect and resolve network and security issues.

XOps transforms millions of raw events into consumable incident stories—correlated across users, devices, and locations. These stories provide full context and are prioritized by risk, enabling security teams to act quickly, reduce alert fatigue, and respond with confidence. 

XOps provides Cato’s security (XDR) and network (AIOps) capabilities.  It automatically processes events from all licensed Cato products, add-ons, and connected third-party tools with no manual setup required.  

[Click11]
Finally, Cato offers full visibility and control via a flexible management model. 
The Cato Management Applications supports granular access control, ability to configure all policies, and access to detailed analytics and event logs.
All of Cato’s software is fully maintained, enhanced, and secured by Cato and our Engineering, SOC and NOC teams, delivering an automated posture management to our customers.
The account can be self-managed by the enterprise, and Cato and its partners can deliver a fully managed service for customers who want it. 

[closing]
The Cato SASE Cloud is a future proof platform for the digital business. As needed, Cato can be gradually deployed across use cases while coexisting with your current network and security infrastructure. 

Ultimately, customers often replace networking and security point solutions deployed in their infrastructure with Cato’s converged platform. They realize material benefits by optimizing spend, improving agility and responsiveness to the business, and enhancing security posture.
